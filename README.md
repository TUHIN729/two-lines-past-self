Two lines to my past self: don't trade my grandfather's old film camera for a new phone at the school fair — the phone died within a year, but the camera held the only photographs of him, and no shop on earth sells those back.

Line 1 warns my past self about one specific moment, in a single sentence. Line 2 says in one sentence why that moment mattered and what changed because of it: a shiny new phone, obsolete in a year, traded away the only photographs of my grandfather — an irreversible loss no money can undo.

## Run it

```sh
node main.ts
```

The program writes exactly two lines (214 characters) to `/output/entry.txt`. To write to a different directory, set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
